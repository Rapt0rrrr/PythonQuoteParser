Python Web Scraper (Quote Parser)

Скрипт для автоматизации сбора данных с сайта-песочницы `quotes.toscrape.com`. Собирает цитаты, авторов и теги, а затем сохраняет их в структурированный файл CSV.

Стек технологий:
Python 3.14
Requests (отправка HTTP-запросов)
BeautifulSoup4(парсинг HTML-разметки)
CSV & OS (сохранение и работа с файловой системой)

 Функционал:
* Обход пагинации (проходит по всем страницам сайта).
* Извлечение текста, автора и списка тегов.
* Обработка ошибок сети и передача заголовка `User-Agent` (имитация браузера).
* Задержка между запросами (`time.sleep`), чтобы не нагружать сервер.
* Экспорт данных в формат CSV с кодировкой UTF-8.
